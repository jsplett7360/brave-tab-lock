Locking

Inactivity means no keyboard or mouse input on this computer, or (if the box below is ticked) the browser not being the focused app. The check runs about every 30 seconds.

What to lock

One site per line. mail.proton.me means exactly that site; *.bank.com also covers bank.com and every address ending in .bank.com. While locked, other sites keep working, and any tab that opens a listed site is hidden at once.

Lockdown mode (under Advanced) always locks all tabs.

Tabs stay open behind the lock screen, so they keep their place and container and you stay signed in. Their addresses and titles stay in each tab’s Back history and in the browser’s own files (Tab Lock can’t erase those). Pressing Back on a locked tab can show the page for a split second before Tab Lock hides it again. If a page has to reload when you unlock, unsaved input on it is lost; pages that ask “Leave site?” always reload.

Wrong PIN

After 5 wrong attempts, each further attempt has to wait longer: 30 seconds, then 1 minute, 2 minutes and so on, up to 1 hour.

Wrong recovery codes count too. In the default mode, erasing closes the hidden tabs; the browser’s own “recently closed” list may still be able to reopen them.

Advanced

Lockdown mode closes your tabs when Tab Lock locks, saves them encrypted on this device, and reopens them when you unlock. Use it if you don’t want locked tabs kept in the browser’s tab history.

  • It doesn’t work with Brave Containers yet: tabs come back outside their container, and you’ll be signed out of the sites in them.
  • Sites where you use “Forget me when I close this site” may sign you out.
  • Anything typed into a page but not submitted is lost.
  • It doesn’t replace disk encryption, your computer’s lock screen, or other security practices. It covers one narrow case: someone using your computer while it’s already unlocked.

PIN or passphrase

The PIN is managed by your Mac — rerun the installer to change it.

Recovery code

Recovery codes are off because your PIN is managed by your Mac. Run the installer again to change it.

A recovery code resets a forgotten PIN and still opens your hidden tabs. Creating a new one makes the old one stop working.

Private windows

To protect private windows: open brave://extensions, choose Tab Lock → Details, and turn on “Allow in Private”. Private-window tabs are only ever kept in memory, never written to disk. Tab Lock’s lock screen can’t open inside private windows, so in every mode locking closes the private tabs it locks, which ends that private session (its logins and cookies are gone). Brave’s private windows with Tor don’t run extensions, so Tab Lock can’t hide or block them.

Keyboard shortcut

The default is Control+Shift+L on Mac (Ctrl+Shift+L elsewhere). Change it at brave://extensions/shortcuts. Clicking the Tab Lock toolbar button also locks immediately.
